Privacy Policy

Last updated: October 30, 2026

The short version

Unlinked does not collect, transmit, sell or share any personal data, browsing history or page content. It has no analytics, no tracking and no servers.

The Chrome extension

Unlinked is a Chrome extension that hides unwanted posts in the LinkedIn home feed.

  • Where it runs. Only on www.linkedin.com. It reads the feed in your browser to decide which posts to hide, and all of that happens on your device.
  • Permissions. Unlinked asks for the storage permission and access to www.linkedin.com. It needs nothing else.
  • Remote code. None. All of the extension’s code is bundled in the package.
  • Third parties. Unlinked sends no data to any third party.

What is stored

  • Your settings (chosen filter, switches, muted keywords and muted people) are saved with Chrome’s storage and synced through your own Chrome sync account, if you have it turned on.
  • Recently seen author names, used for muted-people suggestions, stay on your device.

You can remove all of this by uninstalling the extension or clearing its data.

This website

unlinked.store is a static website. It has no cookies, no analytics, no advertising and no forms. It is hosted on GitHub Pages, so GitHub may process technical data such as your IP address when you visit, as described in the GitHub privacy statement.

Changes

If this policy changes, the new version will be posted on this page with an updated date.
